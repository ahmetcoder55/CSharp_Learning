# C# Learning Journey 🚀

Welcome to my C# learning repository! This project is a comprehensive guide and personal playground where I document my journey of mastering C# and .NET development. It covers everything from basic syntax to advanced topics with clean, documented code examples.

## 📌 Project Overview
The goal of this repository is to store structured, readable, and reusable C# code snippets. Each topic is separated into its own section or file to keep the project modular and easy to navigate.

---

## 📚 Topics Covered So Far

### 🔀 1. Conditional Statements
* **Concepts:** `if`, `else if`, `else`, and `switch-case`.
* **Purpose:** Controlling program flow based on user inputs and evaluation logic.

### 🔁 2. Loops & Anatomy of a Loop
* **Concepts:** `for`, `foreach`, `while`, `do-while`, and control keywords (`break`, `continue`).
* **Purpose:** Understanding how to write efficient code blocks that repeat tasks and automating iterations safely.

### 🗃️ 3. Arrays & Lists
* **Concepts:** Fixed-size Arrays, Dynamic Lists (`System.Collections.Generic`).
* **Purpose:** Learning how to store, manage, and manipulate collections of data based on performance and flexibility needs.

### ⚙️ 4. Methods (Functions)
* **Concepts:** Void methods, return values, parameters, and Method Overloading.
* **Purpose:** Writing modular, reusable, and organized code blocks following clean code principles.
